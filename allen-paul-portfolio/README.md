# Allen Paul Cabic — Personal Portfolio

Single-page personal portfolio built with semantic HTML5, CSS3 (with 3D perspective transforms), and vanilla JavaScript.

## Structure
- `index.html` — Main single-page document
- `css/style.css` — Theme variables, responsive grid layouts, and 3D depth styling
- `js/script.js` — Mobile navigation, scroll spy, pointer perspective, and clipboard helper
- `assets/` — Custom local SVG visuals and favicon
